# Reflex — 10-Minute Demo Script

**0:00–1:00:** Explain the problem and the three roles.

**1:00–3:00:** Retailer login → New Delivery → enter customer, phone, address and item → submit. Point out **Open**.

**3:00–5:00:** Dispatcher login → Deliveries → Assign → enter `rider@reflex.test`. Point out **Assigned**.

**5:00–7:30:** Rider login → Deliveries → Pick up → **Picked Up** → Deliver → **Delivered**.

**7:30–8:30:** Show the completed journey: Open → Assigned → Picked Up → Delivered.

**8:30–10:00:** Explain the JSON storage decision and other trade-offs.

If live demo fails, explain the same workflow and show `backend/data/db.json` plus the architecture document.
