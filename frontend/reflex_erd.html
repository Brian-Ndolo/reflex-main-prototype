🌐 REST API Surface — Mapped to Entities
Method Endpoint Description
POST /api/login Authenticate user (users)
GET /api/deliveries List deliveries (role-filtered)
GET /api/deliveries/:id Single delivery + history
POST /api/deliveries Create delivery (retailer)
DEL /api/deliveries/:id Cancel / delete delivery
PATCH /api/deliveries/:id/accept Rider claims delivery → Claimed
PATCH /api/deliveries/:id/assign Dispatcher assigns → Assigned
PATCH /api/deliveries/:id/status Advance delivery status
POST /api/deliveries/:id/notify-owner Send email notification
POST /api/riders Create rider account (dispatcher)
POST /api/mpesa/stk-push Initiate M-Pesa STK push
GET /api/mpesa/status/:id Poll payment status
POST /api/mpesa/callback Safaricom webhook → update payment
GET /api/earnings/:riderId Rider PAID earnings summary
GET /api/health Storage mode health check
